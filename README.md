## 🌟 Key Website Features

1. **Real-Time Live Status Calculator**:
   - Automatically detects current Indian Standard Time (IST) and displays whether DeraKhas is currently **OPEN** or **CLOSED**, along with closing/opening hours.
2. **Interactive Menu with Instant WhatsApp Ordering**:
   - Filter items dynamically across Burgers & Sandwiches, Garlic Breads & Snacks, North Indian Gravies, Chinese Sizzlers, and Shakes/Mocktails.
   - 1-click WhatsApp order button that drafts the order with item details directly to the cafe's WhatsApp number.
3. **Table Reservation System**:
   - Date picker, guest count, time slots, and seating preference (Lounge Wood Booth vs Open Dining vs Party Hall).
   - Generates pre-formatted instant confirmation message for WhatsApp.
4. **Party Hall & Event Banquet Modal**:
   - Dedicated inquiry workflow for Birthday Parties, Anniversaries, Kitty Parties, and Corporate Meets.
5. **SEO & Structured Microdata**:
   - Rich JSON-LD `Restaurant` schema with geolocation coordinates (`28.3801479° N, 79.4215027° E`), opening hours specification, aggregate ratings, and cuisine tags.
6. **Mobile First & Responsive**:
   - Smooth navigation drawer, glassmorphism design, fast loading, zero external framework dependencies.

## 🚀 How to Run Locally

You can preview the website instantly by opening `index.html` in any web browser, or running a simple local server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js npx
npx serve .
```

Open `http://localhost:3000` to view the website.

---

## 🌐 Deploy to GitHub Pages

1. Go to repository **Settings** > **Pages**.
2. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
3. Click **Save**. Your site will be published live in seconds!
